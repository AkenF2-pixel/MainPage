Google Classroom

Import your Classroom assignments into the Assignments tab. Ones you have turned in are ticked off for you. You need a free Google client ID once. It only asks to read your courses and your own coursework.

How to get a client ID
  1. Open console.cloud.google.com and create a project.
  2. Under APIs and services, then Library, enable the Google Classroom API.
  3. Set up the OAuth consent screen. Choose External, add your own Google account as a test user, and add the scopes .../auth/classroom.courses.readonly and .../auth/classroom.coursework.me.readonly.
  4. Under Credentials, create an OAuth client ID of type Web application. In Authorized JavaScript origins add the address of this page without the path, for example https://your-username.github.io
  5. Copy the client ID and paste it above. Google will warn that the app is unverified. Press Advanced, then continue. School accounts may be blocked if your school limits third-party apps.
